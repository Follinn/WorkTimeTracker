# Табель учёта рабочего времени

Учебное Java-приложение для учёта смен сотрудников, формирования месячных отчётов и расчёта оплаты.

## Состояние реализации

Реализованы модели, хранение смен в месячном табеле, разбиение смен на типы времени
и подсчёт общей длительности и длительности по типам за произвольный период.
Оплата, месячный отчёт и проверка нормы будут добавлены на следующих этапах.
Тестами проверены модели, табель, разбиение смен и расчёт за период:
ночные границы, праздники, приоритеты типов, суммирование смен без перерывов,
полночь, граница месяца и оба перевода часов в `Europe/Berlin`.
Этот часовой пояс используется в тестах; пример в `Main` работает с `Europe/Moscow`.

## Планируемые возможности

- Учёт сотрудников и смен.
- Разделение времени на обычное, ночное, сверхурочное и праздничное.
- Отчёт за месяц с суммой оплаты в копейках.
- Учёт смен через полночь и переходов на летнее время.
- Проверка нормы рабочего времени.

## Правила расчёта

| Тип времени | Условие | Коэффициент |
| --- | --- | ---: |
| Обычное | Остальное время | 1,0 |
| Ночное | 22:00–06:00 | 1,2 |
| Сверхурочное | После 8 отработанных часов за местные сутки | 1,5 |
| Праздничное | Дата входит в список праздников | 2,0 |

При совпадении условий приоритет такой: **праздничное → сверхурочное → ночное → обычное**. Коэффициенты учебные. Длительность считается по фактическому времени, оплата округляется до копейки один раз за месяц (`HALF_UP`).

## Структура

- `model` — сотрудники, смены, табель и отчёт.
- `service` — разбиение смен, подсчёт времени, оплата и проверки.
- `exception` — исключение при превышении нормы.
- `Main.java` — пример запуска.

## Сборка и проверка

Требуются JDK 21 и Maven 3.9 или новее. Основной код находится в `src`,
тесты JUnit 5 — в отдельном каталоге `test`; существующие пакеты сохранены.
При первом запуске Maven требуется доступ к интернету для загрузки зависимостей.

```bash
mvn clean test
mvn compile exec:java
mvn javadoc:javadoc
```

Результаты сборки и документация находятся в `target`.

## Учебные допущения

Правила выше являются учебной моделью, а не реализацией трудового законодательства.
Ночь начинается в 22:00 включительно и заканчивается в 06:00 исключительно.
Праздники задаются `Set<LocalDate>`. Дневной порог настраивается и в примере
равен 8 фактически отработанным часам. Несколько смен одного сотрудника
за местные сутки суммируются, перерывы не учитываются. Даты и часы определяются
в часовом поясе табеля, фактическая длительность — через `Instant`.
Сотрудники различаются по ID; ID и ставка должны быть положительными.
Пересечения смен одного сотрудника запрещены, соприкосновения допустимы.
Табель хранит полные смены, пересекающие его месяц, включая переходящие границу месяца.


## Подсчёт времени за период

`TimeCalculator` принимает настроенный `ShiftSplitter`. Его часовой пояс должен
совпадать с часовым поясом табеля. Методы `calculateTotal` и `calculateByType`
получают список полных смен одного сотрудника и границы периода типа `Instant`.
Период `[начало, конец)` включает начало и исключает конец. Совпадающие границы
задают пустой период с нулевым результатом; обратный порядок границ запрещён.

Сначала полные смены разбиваются по типам, затем каждый отрезок пересекается
с периодом. В список нужно включать и более ранние смены тех же местных суток:
они влияют на дневной порог, хотя их длительность за пределами периода
не попадает в результат. Например, у смены 09:00–19:00 в периоде 16:00–18:00
будет один обычный и один сверхурочный час при пороге 8 часов.

`calculateByType` возвращает неизменяемую карту со всеми четырьмя типами;
для отсутствующих типов длительность равна нулю. `calculateTotal` возвращает
сумму длительностей. Расчёт сохраняет секунды и наносекунды, без округления.
